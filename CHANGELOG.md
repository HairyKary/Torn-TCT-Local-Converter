# Changelog

All notable changes to the Torn TCT + Local Hover Converter are listed here.

## [1.2.0] - 2026-10-12 (beta)
- Removed persistent clocks; the converter now appears only when hovering over a recognized timestamp.
- Standardized TCT and local displays to 24-hour time.
- Added compact tooltip that follows the pointer and hides when leaving a recognized timestamp.
- Added support for several full-date, ISO-style, and time-only formats.
- Prepared GitHub metadata and Tampermonkey auto-update URLs for public distribution.

## [1.1.0] - earlier prototype
- Added draggable time display in the pre-release prototype.

## [1.0.0] - earlier prototype
- Introduced dual TCT/local clock and time conversion functionality.
